# General Information

All the information needed to get the basics of the game.  
<font color="#D94C4C">**Reading this document is mandatory for you as the Any% section is very short.**</font> For anything described in this guide, it is assumed that the elements described here have been taken into account.

## Controller or keyboard ?

**Both input devices** (XInput & DualSense) and **keyboard** are OK to use to play the game as the WR and top 2 use respectively a controller and a keyboard. However, playing **with a controller** will be better in any way since you can smooth steer.

## Driving techniques

If you're using a controller, try to smooth steer as much as you can without making too many rapid analog stick movements unless you have to take very sharp corners.

Use `hood cam` to help judge corners better.

Manual gearbox is the **"fastest"** compared to automatic, if possible use it.  
> **Remark** : When using manual gears, if you're in the air for long enough (for example, on that large jump on `Panamint Valley`), your speedometer needle will start to go anticlockwise, and when you land you will lose a lot of speed thanks to that. To prevent this, **use nitrous as the needle is about to drop and hold it until you land**.

## Known game bugs [PC only]

The game can crash alot, depending on the specs you're playing the game on.  
If your game crashed and you have custom controls, check them when you start the game again because there is a chance that they've been reset back to default.

The higher the fps, the less grippy the cars are and the more unstable the game is, hence the 30 FPS limit / use of the vsync.

You can softlock the game on certain stages, resulting in an Alt+F4. The softlock happens when you try to skip a cutscene, which will be explained how to do it below.

## Cutscene skip

Every cutscene seen in the game **aren't skippable**. And during the gameplay, you will tackle with alot of them, especially **at the start of events**. However, you can skip most of them.

To skip a cutscene like this (at the start of an event), just **restart the event**. Simple as that.

## Glitches and exploits

For each track, around their map, there are reset triggers placed anywhere the developers don't want you to go. However, it appears to be very easy to **break these reset triggers** by using the resets, as well as either a gas station **OR** a mid-event cutscene.

**Spam the reset button until the game considers you to be in control** (you'll know if it has worked if you see a black screen fade followed by your car going in and out of existence) and either **going into and exiting a gas station OR going into a mid-event cutscene**. For whatever reason, this breaks all reset triggers, allowing you to go wherever you want (in other words, you can perform OOBs).

**Note 2**

> Some are significantly more consistent if you play the game with the in-game v-sync (with the in-game v-sync even being a requirement for a lot of them) because it has a special property which appears to delay the amount of time it takes until a manual hard reset is allowed to be triggered. Meaning it can't interrupt the buggy reset that you need to get to setup the glitch. Once you're in this mode, you have to be aware of some **very important** side effects of this bugged mode.
>
>> 1. You cannot manualy reset your car.
>> 2. You pretty much enter a permadeath mode, so if you wreck your car, you're toast. And the only way to become less toast is to restart the event.
>> 3. The timer in make up time and battle events completely breaks. So, even if you run out of time, you won't fail the event.
>> 4. You can't get killed on any mob events. Not from the Cayennes, the chopper or even explosives, similar to a God Mode.

### "Unswap" car glitch

Unlike the `Car swap` glitch (which allows you to change the car you're using to any car in the game you have unlocked), the `Unswap car` glitch does the opposite.

<span style={{ fontSize: '1.5rem', fontWeight: 'bold' }}>How does it work ?</span>

When you choose a car from a `Car select` screen and you restart the event at a certain moment during the black fade-in screen, you can **keep the car you were driving <u>before</u>** being asked to choose a new car.

To go deeper, during this fade-in screen, the game will change the internal event ID _(from the last Stage 7 event ID to the first Stage 8 event ID)_. You can see it on the UI if you pause buffer :

* You're still on Stage 7 if you see the `Pause menu` text on top-left.
* You're "considered" on Stage 8 if you don't see the `Pause menu` text anymore.  
> :warning: If you're using an autosplitter, Livesplit will split during the switch.

The thing is you can still pause during the switch and if you restart the event after having switched ID, the glitch will happen.

> **Note** : you can conclude that the glitch worked if you see **a flickering black screen** during the loading screen after having restarted the event (it's like the load screen is restarting itself).

This glitch can be used for NG+ **and also** NG runs.

* NG

> This glitch allows you to **keep the Lamborghini Gallardo Balboni after Stage 7 for Stage 8** instead of driving with the Audi R8 _(which is way slower than the Sesto)_.

* NG+

> This glitch allows you to **keep the Lamborghini Sesto Elemento during the whole run**.

There are two ways how to perform the glitch : the **Autosplit** method and the **Elephant** method.
